Connect fal.ai

Kings Studio runs every model through fal.ai except "Seedance 2.5 · Replicate", which uses your Replicate token (the Replicate key… button below). You pay only for what you generate, with no subscription.

  1. Sign in at fal.ai/dashboard/keys and create an API key.
  2. Add a few dollars at fal.ai/dashboard/billing.
  3. Paste the key below. It's saved only on this computer.

Connect Replicate

The "Seedance 2.5 · Replicate" model runs on Replicate, which sells it at ByteDance's own price, about half of fal's. Everything else keeps using fal.ai.

  1. Sign in at replicate.com/account/api-tokens and create a token.
  2. Add a payment method or credit at replicate.com/account/billing.
  3. Paste the token below. It's checked with Replicate and saved only on this computer.
